# Task Completion Checklist
- 実装完了後の必須確認:
  1. 変更に対応するテストを追加/更新したか
  2. `pytest` が通るか
  3. `black .` を実行したか
  4. `isort .` を実行したか
  5. `flake8` が通るか
  6. 秘密情報（APIキー等）がコードやGit差分に含まれていないか
- 配布関連変更時:
  - 必要に応じて `python build_exe.py` を実行しビルド確認
- PR前:
  - タイトルが `feat: ...` 形式等のガイドラインに沿っているか
  - 説明欄に「変更内容」「目的」「確認方法」を記載したか
